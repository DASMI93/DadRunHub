# DadRunner Hub 🏃‍♂️👶🐶

A personalized, mobile-first web app designed for a 33-year-old dad of a 3-month-old, dog owner, and runner.

## 🌟 Key Features
- **Daily Macro & Diet Strategy:** High-protein 1,950 kcal blueprint designed for 15-min quick preps.
- **8-Week Progressive Running Plan:** Interactive checklist with progress tracking saved locally in your phone's browser (`localStorage`).
- **Daily Timeblock Visualizer:** Built around 07:00 / 19:00 dog walks, 08:30-17:00 work hours, and newborn baby care.
- **Strava Title Generator & Zone 2 Pace Calculator:** Fun tools to keep your Strava feed entertaining and target paces on track.

## 🚀 How to Host on GitHub Pages (Free in 2 Minutes)

1. **Create a GitHub Repo:**
   - Go to [GitHub.com](https://github.com/new) and create a public repository named `dad-runner-hub`.

2. **Upload Files:**
   - Upload `index.html`, `styles.css`, `app.js`, and `README.md` into the repository.

3. **Enable GitHub Pages:**
   - Navigate to **Settings** > **Pages**.
   - Under **Build and Deployment**, set Source to `Deploy from a branch`.
   - Select `main` branch and `/ (root)` folder, then click **Save**.

4. **Access on Your Phone:**
   - In ~60 seconds, your site will be live at `https://<your-username>.github.io/dad-runner-hub/`!
   - Open the link on your phone and tap **Add to Home Screen** to use it just like a native mobile app.
